# ArtScope｜昱佐 YuZuo 的 3D 與 2D 美術作品集

UX 使用者經驗設計課程專案：一個以「作品欣賞」為核心的個人數位美術作品集網站。
站內 51 件作品（含 8 件精選）皆為**本人實際作品**，由 `artworks/` 資料夾自動產生資料。

網站名稱 ArtScope 為展覽名（課程規格暫定名），創作者為 **昱佐 YuZuo**。

---

## 一、如何開啟網站

本專案為純前端靜態網站，**不需要安裝任何套件或建置工具**。

### 方式 1：直接開啟（最簡單）

雙擊專案資料夾中的 `index.html`，或用瀏覽器開啟：

```
D:\artScope-project\index.html
```

### 方式 2：本機伺服器（建議，行為最接近正式空間）

```bash
cd D:\artScope-project
npx serve .
# 或
python -m http.server 8080
```

然後瀏覽 `http://localhost:8080`。

> 網站使用一般 `<script>` 載入資料（不使用 ES Module），因此直接用 `file://` 開啟也能正常運作。

## 三、新增／調整作品的完整流程

### 1. 放圖片

把圖片放進 `artworks/` 對應的資料夾：

```
artworks/
├─ 2D 插畫/            放 2D 插畫
├─ 3D 美術/            放 3D 模型渲染圖
├─ 2D 插畫/優質/       放這裡 = 精選（置頂）
└─ 3D 美術/優質/       同上
```

**檔名規則（很重要）**：

| 寫法 | 結果 |
|---|---|
| `幽影王.jpg` | 一件作品，標題「幽影王」 |
| `愛麗絲夢遊-1.jpg`、`愛麗絲夢遊-2.jpg` | 自動合為**同一件作品**的兩張圖片，標題「愛麗絲夢遊」 |
| `十二生肖系列-虎-1.jpg` ~ `-3.jpg` | 同一件作品三張圖，標題「十二生肖系列-虎」 |
| `白無常-2D.jpg` | 結尾的 `-2D` / `-3D` 標記會自動去掉，標題「白無常」 |
| `晏青眠-2D場景.jpg` | 結尾的 `-2D場景` 也會去掉，標題「晏青眠」 |

- 圖片會依結尾數字排序（-1 在前、-2 在後），第一張為封面。
- 圖片格式支援 `jpg / jpeg / png / webp / gif / avif`。
- 2D 與 3D 資料夾裡同名的作品會分開成兩件（因為類型不同）。

### 2. 重新產生作品資料

在專案根目錄執行（需要安裝 [Node.js](https://nodejs.org)）：

```bash
node tools/generate-artworks.mjs
```

輸出會看到類似：

```
已產生 D:\artScope-project\assets\js\artworks.js
作品 51 件（精選 8 件），圖片共 82 張
```

**重新整理網頁就看得到新作品**——不需修改任何頁面程式。
新增或刪除圖片後都要重跑一次這個指令。

### 3. 補上作品文字（介紹、創作故事）

圖片資料是自動產生的，但**文字不會被覆蓋**：
開啟 `assets/js/data.js`，在 `overrides` 中以作品的 slug 為鍵補上文字：

```js
overrides: {
  "3d-十二生肖系列-虎": {
    description: "作品的一句話介紹。",
    story: {
      background: "創作背景……",
      concept: "創作概念……",
      inspiration: "靈感來源……",
      theme: "想表達的主題……",
      process: "製作過程文字……",
      extra: "其他補充故事……"
    },
    process: [
      { stage: "概念設計", image: "artworks/3D 美術/xxx.jpg", caption: "此階段說明" }
    ],
    tags: ["角色", "材質"],
    featured: true,
    sortOrder: 3
  }
}
```

- **slug 在哪裡看？** 開啟 `assets/js/artworks.js`，每件作品的 `slug` 欄位就是；
  格式為「類型-標題」，例如 `3d-十二生肖系列-虎`、`2d-幽影王`。
- 想顯示哪幾段就補哪幾段，其餘留空即自動隱藏，不會出現空白區塊。
- 重新執行產生腳本後，`overrides` 的文字依然有效。

### 欄位缺省時的行為

| 欄位 | 省略時的行為 |
|---|---|
| `description` | 卡片不顯示說明文字，詳情頁不顯示介紹段落 |
| `tags` | 無標籤，不影響其他功能 |
| `story`（整個或任一欄位） | **該段落自動隱藏**，全部沒有則整個「創作故事」區塊隱藏 |
| `gallery`（只有一張圖） | 圖片切換按鈕自動隱藏 |
| `process`（空陣列） | **「製作過程」區塊自動隱藏** |
| `featured` | 預設 `false`，不會排在最前面、不出現在首頁精選 |
| `coverImage` 缺圖／路徑錯誤 | 顯示「圖片載入失敗」替代狀態，版面不會壞掉 |

### 想手動新增整件作品（選配）

少數不在 `artworks/` 資料夾的作品，可以直接寫在 `data.js` 的 `artworks` 陣列，
它會排在自動產生的作品之後。欄位結構：

```js
{
  id: "work-manual-01",                // 唯一，不可重複
  slug: "manual-work-01",              // 網址用：artwork.html?slug=manual-work-01
  title: "作品名稱",
  type: "3d",                          // 必須是 categories 中的 id（"2d" / "3d"）
  coverImage: "artworks/3D 美術/xxx.jpg",
  description: "作品的簡短介紹。",
  tags: ["角色"],
  featured: false,
  sortOrder: 900,                      // 數字愈小愈前面（精選作品才會用到）
  demo: false,
  story: { background: "", concept: "", inspiration: "", theme: "", process: "", extra: "" },
  gallery: [{ src: "artworks/…/a.jpg", alt: "圖片替代文字", caption: "" }],
  process: [{ stage: "概念設計", image: "artworks/…/p1.jpg", caption: "" }]
}
```

## 四、作品排序規則

1. **精選作品固定排在最上面**：放在 `優質/` 資料夾的作品即為精選，
   會出現在首頁「精選作品」區塊，並排在作品探索列表最前面。
   精選之間的順序＝`overrides` 的 `sortOrder`（沒寫則依標題排序）。
2. **其餘作品每次造訪隨機排序**：2D 與 3D 交錯混排，每次重新整理順序不同；
   同一次瀏覽內（同一個分頁）順序保持一致，不會點一張就跳一次。
3. 相關作品、上一件／下一件也遵循同一套順序。

## 五、其他可調整的地方

- **LOGO 與名稱**：LOGO 為 `artworks/我的LOGO.png`（替換此檔即可更新全站與網頁圖示）；
  名稱與路徑在 `assets/js/data.js` 的 `config.creator`、`config.logo`。
- **改分類**：編輯 `data.js` 的 `categories`（增減後首頁分類入口與篩選列會同步更新）。
- **改展覽介紹／聯絡方式**：編輯 `data.js` 的 `about`。
- **改視覺（顏色／字體／間距）**：全部集中在 `assets/css/tokens.css`。
- **正式展示模式**：把 `data.js` 的 `config.dataMode` 改為 `"formal"`，
  介紹頁的「預留區塊」提示就會隱藏（作品不受影響）。

## 六、功能清單

### 已完成

- **五個頁面**：首頁、作品探索、作品詳情、收藏清單、展覽介紹，導覽與頁尾一致。
- **作品資料自動化**：掃描 `artworks/` 產生資料，同檔名多張圖自動合件，新增作品不需改頁面。
- **排序**：精選（優質）置頂、其餘隨機排序、同一次瀏覽內順序穩定。
- **作品瀏覽**：卡片點擊進詳情、上一件／下一件切換、返回作品探索（會還原上次的篩選條件）。
- **分類與篩選**：精選快速篩選、作品類型、系列標籤、文字搜尋（前端比對）、目前條件顯示、單項或全部清除、結果數量、無結果空狀態。
- **排列切換**：規則網格／編輯式網格（不等高，但 DOM 閱讀順序不變）。
- **圖片檢視器**：點擊放大、全螢幕燈箱、Esc 關閉、← → 或按鈕切換、手機觸控左右滑動、圖片計數、載入失敗狀態、關閉後焦點歸位。
- **圖片切換**：縮圖列表、上一張／下一張、說明文字同步更新；只有一張圖時自動隱藏切換介面。
- **製作過程**：階段分頁（含鍵盤左右鍵操作）、階段名稱／說明同步更新；無資料時整區隱藏。
- **創作故事**：六個欄位分段呈現、無資料欄位自動隱藏、長篇故事可展開／收合。
- **收藏**：卡片與詳頁皆可收藏、按鈕狀態與文字更新、toast 提示、導覽列數量徽章、localStorage 保留、收藏清單頁即時同步、空狀態與失效收藏清除。
- **分享**：複製作品網址（含 fallback）、支援的瀏覽器顯示系統分享。
- **狀態設計**：正常、滑鼠移入、按鈕按下、已收藏、已取消收藏、無搜尋結果、收藏為空、圖片載入失敗、作品不存在、手機選單開關。
- **響應式**：桌機（≥1024）、平板（600–1024）、手機（<600）各自調整版面；手機單欄、導覽改為選單面板、按鈕觸控尺寸 ≥40px。
- **無障礙**：跳至主要內容連結、鍵盤可操作全部功能、焦點樣式、燈箱焦點鎖定與 Escape、`aria-pressed`／`aria-current`／`aria-live`、圖片替代文字、狀態不只用顏色（✓ 記號、文字標示）、`prefers-reduced-motion` 停用動畫。
- **資料與程式分離**：作品圖片→資料→畫面三層分開，新增作品不需改頁面。

### 尚未完成／待提供

- 各作品的文字：一句話介紹、創作背景／概念／靈感／主題等故事欄位（等你提供後填進 `data.js` 的 `overrides`）。
- 介紹頁的展覽理念、創作者介紹、聯絡方式（`about` 欄位目前留空，顯示預留狀態）。
- 真正的高解析度原圖檢視（目前放大檢視使用同一張圖片檔案，不假裝提供更高解析度）。
- 第二／第三階段的視覺精修（頁面轉場、視差、更細的排版微調）仍可依需求再加強。

| 流程 | 操作路徑 |

## 九、常見問題

**Q：新增圖片後沒出現？**
確認圖片放在 `artworks/2D 插畫/` 或 `artworks/3D 美術/`（不能是更深的未知子資料夾），
並且**重跑** `node tools/generate-artworks.mjs` 後重新整理網頁。

**Q：兩張圖想合成同一件作品？**
檔名只差結尾數字即可，例如 `角色-1.jpg`、`角色-2.jpg`。

**Q：怎麼讓某件作品排在最上面？**
把它放進對應類型的 `優質/` 資料夾，重跑產生指令。

**Q：圖片顯示「圖片載入失敗」？**
路徑錯誤或檔案不存在。路徑以專案根目錄為基準，寫成 `artworks/3D 美術/…`。
也要確認檔名中的空白與中文沒有被改動。

**Q：跑產生指令時出現亂碼或找不到檔案？**
確認是在專案根目錄（`artScope-project`）執行 `node tools/generate-artworks.mjs`，
並確認 Node.js 已安裝（`node -v`）。

**Q：收藏沒有保留？**
部分瀏覽器的隱私模式會停用 localStorage，此時收藏只在本次瀏覽有效。
若直接以 `file://` 開啟時收藏無法保留，請改用本機伺服器開啟（見「如何開啟網站」方式 2）。

**Q：想恢復佔位圖片？**
執行 `powershell -ExecutionPolicy Bypass -File tools\make-placeholders.ps1`
（佔位素材目前網站未使用，僅保留供之後版型測試）。
